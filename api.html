How to use the API

Base URL:
Authentication: send your key in the X-Api-Key header.

1. List services

Each service key looks like platform.service.type (e.g. tiktok.followers.avg).

curl "https://YOUR_API/api/public/services" -H "X-Api-Key: YOUR_KEY"

2. Check your balance

curl "https://YOUR_API/api/public/balance" -H "X-Api-Key: YOUR_KEY"

3. Add an order

curl "https://YOUR_API/api/public/add" -X POST \
  -H "X-Api-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "service": "tiktok.followers.avg", "link": "https://tiktok.com/@yourname", "quantity": 500 }'

4. Check order status

curl "https://YOUR_API/api/public/status?order=123" -H "X-Api-Key: YOUR_KEY"

Status values: pending → completed (or canceled, which is refunded automatically).
